# Graphic elements (signature devices)
Vector shapes that give the brand its look. Use them as CSS backgrounds, `<img>` or inline SVG.

| File | Use |
|---|---|
| dune-divider-*.svg | Section transition. Place at the bottom of a section, colour it as the NEXT section's background. Stretch full width, height 80-160px. |
| arch-outline-rose-400.svg | Thin offset outline behind an arch-masked photo (offset 16-28px). |
| sun-discs.svg | Two overlapping circles. Partly hidden behind a photo or section edge. Max 2 per viewport. |
| sun-gradient-disc.svg | Single rose sun. Use as a large decorative disc behind headlines or the logo icon. |

Rules: decorative only, never behind small text, never recoloured outside the palette, never animated faster than 480ms.
