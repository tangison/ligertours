# Page specs

Pages: Home, Tours (index + one page per tour), Activities, About, Gallery, Contact, Privacy Policy, Terms, 404. Keep all real tour, activity, about and contact content that already exists in the project. Rewrite only for the voice rules. Do not invent facts, prices, awards or testimonials.

## Global
- **Header:** fixed. Over a hero it is transparent with the ON-DARK logo. After 80px scroll it becomes rose-50 with the PRIMARY-ROSE logo and a hairline rose-300 border. Logo never in a box. Nav in Archivo uppercase 13px, 0.1em tracking. Right side: primary button "Plan my trip". Mobile: full-screen drawer on night, on-dark logo, large Archivo links, WhatsApp button.
- **Footer:** night background, on-dark logo, contact details, nav, social, small print. Dune divider above it (night). Credit line stays as is.
- **Floating WhatsApp button:** bottom right, brand fill, 56px. Link `https://wa.me/264814722552`.
- **Page header (inner pages):** 50svh photo with dusk overlay, eyebrow, script H1.

## Home (in this order)
1. **Hero.** `safari-vehicle-red-sand` 16x9, dusk overlay, headline lockup (kicker + script H1), one-line lead, buttons "Plan my trip" (primary) and "View tours" (ghost). Slow parallax max 12%.
2. **Intro.** Two columns on rose-50. Left: eyebrow, H2, 2 short paragraphs, link. Right: `gemsbok-golden-light` 4x5 in an arch with offset outline and sun discs behind.
3. **Signature tours.** Rose-100 background. H2 + horizontal scroller (mobile) or 3-column grid (desktop) of 4x5 arch cards: image, duration eyebrow, H3 title, one-line description, text link "View the tour".
4. **Landscape band.** Full-bleed `deadvlei-blue-sky` with overlay, large script phrase, no button. Dune divider into the next section.
5. **Why Liger.** Rose-200 panel. Real differentiators as 3-5 items: number in script font, Archivo H3, 2 lines.
6. **Activities.** 2x3 grid of image tiles (1:1) with title overlay on dusk gradient.
7. **Stay.** `thatched-chalets-hillside` 16x9 and `red-dune-timber-lodge` 4x5 side by side with short copy.
8. **Testimonials.** Only the real ones already supplied. Large quote in Schibsted Grotesk 24px, name and country in Archivo label. No stars unless supplied.
9. **Final call to action.** Night section, sun discs, script H2, buttons "Plan my trip" and "WhatsApp us".

## Tours index
Page header, filter by length (short / long) using simple buttons, grid of arch cards. Every tour has: image, duration, route in one line, price only if supplied.

## Tour detail
Hero 16x9, summary bar (duration, group size, season, if supplied), overview, day-by-day timeline (vertical line rose-300, day number in script), highlights, included/not included (two columns), gallery, enquiry panel (sticky on desktop) with form + WhatsApp.

## Activities / About / Gallery / Contact
- **Activities:** alternating image/text rows, 4x5 arch images, duration and what to expect.
- **About:** founder story with arch portrait or landscape, registered-operator line if supplied, values grid.
- **Gallery:** masonry of all images, lightbox with keyboard support and captions.
- **Contact:** form (name, email, phone, dates, group size, message), validation messages, success state, WhatsApp, phone, email, opening hours, map link.

## Image use summary
Hero: safari-vehicle-red-sand. About: gemsbok-golden-light. Landscape band: deadvlei-blue-sky. Stay: thatched-chalets-hillside, red-dune-timber-lodge. Gallery: all. Cards: use crops 4x5.
